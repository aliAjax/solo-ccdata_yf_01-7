# Pixel Loom · 多图层关键帧工作台

纯前端（单文件 `index.html`，无需后端、无构建步骤）的像素动画工作台。直接用浏览器打开 `index.html` 即可使用，项目自动保存在浏览器 localStorage。

## 功能

- **多图层 / 帧**：每帧包含任意数量图层；支持添加、复制、删除、拖拽排序、显示/隐藏、锁定、不透明度与 12 种混合模式（正常/正片叠底/滤色/叠加/变暗/变亮/颜色减淡/颜色加深/强光/柔光/差值/排除）。
- **像素绘制**：画笔、橡皮、洪水填充、取色；锁定或隐藏的图层不可绘制。
- **关键帧与补间**：位置 X/Y、缩放、旋转、不透明度 5 个通道均可打点；同通道关键帧之间自动生成线性/缓入/缓出/缓入缓出补间，搓条与舞台实时预览。关键帧菱形可在搓条上直接拖拽改时间。
- **时间线**：帧卡片拖拽排序、一键复制（像素与关键帧深拷贝）、逐帧时长（ms）、重命名；搓条按各帧时长比例显示分段；循环/单次播放。
- **撤销 / 重做**：覆盖图层编辑、像素绘制、关键帧/补间、缓动、帧排序与时长等全部操作；连续拖动合并为一次历史；Ctrl/⌘+Z、Ctrl/⌘+Shift+Z（或 Y）。
- **持久化**：自动保存（防抖）+ 手动 Ctrl/⌘+S；刷新后完整恢复帧、图层、关键帧、外观与循环设置；自动读取并迁移旧版 v1 存档；对损坏/脏数据做校验清洗。
- **导出**：
  - 当前播放头所在合成帧 PNG（可选 1/2/4/8× 倍率）；
  - 精灵表 PNG + JSON 元数据（帧索引、局部时间、行列数、单帧尺寸、各帧时长）；
  - 循环/单次 APNG 动画（优先使用 `CompressionStream` 真 zlib 压缩，老浏览器回退无压缩）。
- **键盘 & 窄屏**：空格播放、方向键切帧/切图层、B/E/G/I 切工具、Home 回头、Esc 取消拖拽；所有拖拽（图层、帧、关键帧）基于 Pointer Events，触屏可用；≤1100px / ≤760px 响应式布局。

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| Ctrl/⌘ + Z / Shift+Z / Y | 撤销 / 重做 |
| Ctrl/⌘ + S | 保存 |
| ← → | 上 / 下一帧 |
| ↑ ↓ | 上 / 下一图层（显示顺序） |
| B / E / G / I | 画笔 / 橡皮 / 填充 / 取色 |
| Home | 回到时间线开头 |
| Esc | 取消当前关键帧拖拽 / 暂停 |

双击图层名或帧名可重命名。

## 测试

无外部依赖，Node ≥ 18：

```bash
node test/model.test.js   # 模型层 198 项断言（补间/历史/持久化/极端操作/PNG·APNG 字节）
node test/ui.smoke.js     # 精简 DOM 垫片中真实驱动 UI 全链路（53 项）
node test/e2e.render.js   # 光栅化 + APNG 导出/解压端到端（12 项）
```

测试直接从 `index.html` 中抽取脚本执行，不复制业务代码。
